로딩 스피너(Loading Spinner)

로딩 스피너(Loading Spinner)는 시스템이 백그라운드에서 무언가를 처리하고 있음을 사용자에게 알리는 아주 단순하지만 필수적인 UI 요소입니다. "데이터를 불러오는 중이니 잠시만 기다려 주세요"라는 말을 시각적인 언어로 전달하는 것이죠. UX/UI 디자이너이자 개발자의 관점에서 스피너의 역할과 제대로 구현하는 방법을 정리해 드립니다.

로딩 스피너 이미지 예시

스피너의 본질: "사용자의 불안을 덜어주기"

웹사이트에서 아무런 반응이 없는 1~2초는 사용자에게는 10초처럼 느껴집니다. 스피너는 시스템이 멈춘 게 아니라 "열심히 일하고 있다"는 사실을 증명하여 사용자의 이탈을 막는 역할을 합니다.

언제 무엇을 써야 할까? (로딩 UI 비교)

초보 주니어 개발자와 시니어 개발자를 가르는 기준 중 하나가 바로 이 '로딩 상황에 맞는 적절한 UI 선택'입니다.

  • 로딩 스피너: 데이터 로딩 중, 작업 처리 중 - 단순하고 직관적임. 짧은 대기 시간에 적합.
  • 프로그레스 바: 작업 완료 비율을 알 때 - 완료 시점 예측 가능 (파일 업로드, 결제 단계).
  • 스켈레톤(Skeleton): 페이지 레이아웃 로딩 - 실제 콘텐츠 위치에 뼈대만 보여주어 체감 대기 시간 단축.

UI/UX 디자인 가이드라인

위치

중앙 정렬이 가장 일반적입니다. 하지만 특정 버튼을 눌렀을 때 나타난다면 그 버튼 바로 옆에 배치하여 인과관계를 명확히 하세요.

등장 시점

API 호출이 0.5초 이내로 끝난다면 스피너를 보여주지 않는 게 좋습니다. 오히려 스피너가 '번쩍'거리며 나타났다 사라지면 사용자의 눈을 피로하게 만들기 때문입니다. 로딩이 0.5초~1초 이상 길어질 때 보여주는 것이 이상적입니다.

접근성(Accessibility)

시각장애인을 위한 스크린 리더가 이 스피너를 '로딩 중'이라고 읽어줄 수 있도록 aria-busy="true"와 같은 속성을 반드시 추가해야 합니다.

실전 코드 예시 (HTML/CSS)

가장 깔끔하고 현대적인 CSS 기반의 스피너 구현 예시입니다. 별도의 이미지 파일 없이도 CSS로 충분히 구현 가능합니다.

HTML

<div class="loading-overlay" id="loading">
  <div class="spinner"></div>
</div>

CSS (회전 애니메이션)

/* 로딩 오버레이 */
.loading-overlay {
  position: fixed;
  top: 0; left: 0; width: 100%; height: 100%;
  background: rgba(255, 255, 255, 0.7);
  display: flex; /* 중앙 정렬 */
  justify-content: center;
  align-items: center;
  z-index: 9999;
}

/* 스피너 디자인 */
.spinner {
  width: 50px;
  height: 50px;
  border: 5px solid #f3f3f3; /* 옅은 회색 테두리 */
  border-top: 5px solid #3498db; /* 돌아가는 부분 강조 색상 */
  border-radius: 50%;
  animation: spin 1s linear infinite; /* 1초마다 무한 회전 */
}

@keyframes spin {
  0% { transform: rotate(0deg); }
  100% { transform: rotate(360deg); }
}

jQuery (상태 제어)

// 로딩 시작
function showLoading() {
  $('#loading').show();
}

// 로딩 종료
function hideLoading() {
  $('#loading').hide();
}

// 예시: API 호출 시 활용
$.ajax({
  url: 'your-api-url',
  beforeSend: function() { showLoading(); },
  complete: function() { hideLoading(); },
  success: function(data) { /* 성공 로직 */ }
});
